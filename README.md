This is my seventh game (wow). This game is heavily inspired by doodle jump. I didn't make the art and add sound on it cuz i was pretty busy with college. Everything is pretty similar with doodle jump there is:
1. jetpack
2. trampoline
3. crumbling

but i added some more mechanics such as:
1. Bird
2. Bat
3. Spike
4. Biome when you got higher

Here is something to keep in mind:
1. Green platform is platform
2. Blue platform is moving platform
3. Red platform is trampoline platform
4. Blue Lightish platform is crumbling platform
5. Yellow small block is bird
6. Purple small block is a bird 
7. Grey is spike platform


A, D, Left arrow, Right arrow to move left to right,
Space to start,
W, S, Up arrow, Down arrow to move up n down on pause menu
Esc to pause/resume
P to pause

Here's how to play:
1. Space to start
2. A,D,Right,Left arrow to move left to right
3. Enjoy!
M to mute (unfortunately there is no music)
